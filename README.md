# SmartREST - Hono Edition

SmartREST Hono is a template to create REST API microservices using Node.js in TypeScript.

It features:

* Bun package manager
* Hono framework
* Drizzle ORM
* Embedded SQLite

## Setup

To install dependencies:
```sh
bun install
```

To run:
```sh
bun run dev
```

open http://localhost:3000
